# QFlowLearn project site

Public project hub at [qflowlearn.github.io](https://qflowlearn.github.io).

Edit `index.html` and `styles.css` directly. GitHub Pages publishes the root of `main`; `.nojekyll` keeps publication static. No installation or build is required.

The site explains project boundaries and availability. Author and Deliver application repositories remain private. The public QTI library remains at [LongsightGroup/qti3](https://github.com/LongsightGroup/qti3).
